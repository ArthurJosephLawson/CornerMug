## Workflow: LibreSprite → Game Engine

1. **Save `.ase` files in `sprites/ase/<category>/`:** Keep your layered LibreSprite source files organized here for future edits.
2. **Export `.png` files into `sprites/png/<category>/`:** Export flat/transparent PNGs into the matching `png/` subfolder (`File → Save Copy As` or `Export` in LibreSprite). Phaser **only** reads `.png` files from `sprites/png/`.
3. **Register in `ASSETS.md`:** Log new filenames in `sprites/ASSETS.md` so OpenCode knows what assets exist.
4. **Place Props & Collisions Visually (`?edit=true`):** Run the dev server (`npm run dev`), open the room with `?edit=true`, drag your prop PNGs onto the `640x360` interior, draw wall collision boxes, and export the updated room JSON into `src/config/rooms/`.

## How Phaser Loads Your Assets

The root `sprites/` folder is mapped to `/sprites` in Next.js (`public/sprites` symlink or pre-build sync script), so assets load via clean static URLs:

```ts
// Static direction character PNGs (no sprite sheets)
this.load.image('male_left', '/sprites/png/characters/male_left.png');
this.load.image('male_right', '/sprites/png/characters/male_right.png');

// 640x360 full-canvas interior background
this.load.image('interior_1', '/sprites/png/interiors/interior_1.png');

// Individual transparent props
this.load.image('desk_1', '/sprites/png/props/desk_1.png');
